## 开闭原则
1. 对修改开放 对扩展开放 解决方法 
    - 通过接口抽象出 不同类型的 GetArea 传入接口
    - 通过 字典根据类型去进行不同 的方法实现 但是还是要对字典数据改变
2. 修改的的化可能导致范围判断的不准确 使用多层if else 很可能存在着 判断相互以来的情况

interface ICalcGold{
    public int CalcGold();
}

## 里氏替换
1. 修改了伤害的传播路径应该在 GetEffectValue 处理伤害 实际是在 AddStack 爆炸伤害计算
2. 父类允许的行为在子类中被拒绝了 

```cs
enum ItemType{
    _1,
    _2,
}
public class Item
{
    protected int durability;
    protected ItemType _type

    public virtual bool Repair(int amount)
    {
        if( _type != _2)
            durability = Math.Min(durability + amount, MaxDurability);
            return true;

        return false;
    }
}

public class IndestructibleItem : Item
{
    public override bool Repair(int amount)
    {
        super.Repair(amount)
    }
}
```

## 接口隔离
1. 被迫实现不属于他的行为，甚至会触发bug导致角色进行与职业不相符合的行为
2. ICharacterAction 定义了过多的行为 接口的定义过于宽泛 要进行收敛 分成不同的接口

```cs
public interface ITakeDamage
{
    void TakeDamage(int dmg);    // 受击
}

public interface IDropLoot
{
    void DropLoot();             // 掉落——NPC 不需要
}

public interface IPatrol
{
    void Patrol();               // 巡逻——敌人专属
}

public interface ITalk
{
    void Talk();                 // 对话——NPC 专属
}

public class Enemy : ITakeDamage IDropLoot IPatrol ITalk
{
    public void TakeDamage(int dmg) { }
    public void DropLoot() { }
    public void Patrol() { }
    public void Talk() { throw new NotImplementedException(); }
}

public class VillagerNpc : ITakeDamage ITalk
{
    public void TakeDamage(int dmg) { }
    public void DropLoot() { throw new NotImplementedException(); }
    public void Patrol() { throw new NotImplementedException(); }
    public void Talk() { }
}
```

## 依赖倒置原则
为了要兼容不同输入模块 我想要加入一个中间层 将外层输入 规范化
输出层使用规范化后的 输入
比如定义 接口 去约束输入
通过实践响应输入

```cs
interface ILog
{
    public void Log(string msg);
}

public class ConsoleLogger : ILog
{
    public void Log(string msg)
    {
        System.IO.File.AppendAllText("ConsoleLog.txt", msg + "\n");
    }
}

public class FileLogger : ILog
{
    public void Log(string msg)
    {
        System.IO.File.AppendAllText("FileLog.txt", msg + "\n");
    }
}

public class GameEngine
{
    private ILog logger;

    public GameEngine(ILog _logger) => logger = _logger;

    public void Start()
    {
        logger.Log("游戏启动");
    }
}
```
