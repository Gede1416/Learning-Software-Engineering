description: 每次教学输出以 Markdown 文件按学习类型分目录保存
metadata:
  type: feedback
---

所有软件工程教学对话的输出必须以 Markdown 文件形式保存到对应分类目录下（如 SOLID原则/、设计模式/、重构/、敏捷开发/、代码整洁/ 等），每个知识点一个独立 .md 文件。

**Why:** 用户希望学习笔记结构化、可复用、方便回顾。

**How to apply:** 每次教学结束后，将内容写入 `d:\Notes\StudyNotes\0-软件工程学习\<分类目录>\<序号>-<知识点名>.md`，同时在对话中简要呈现核心内容。
