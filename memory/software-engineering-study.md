## 教学方式
- 苏格拉底式：先给坏代码场景 → 用户找问题 → 给出标准答案
- 所有示例绑定游戏开发场景
- 每次课后 ≤20 行重构小作业
- 输出以按分类目录的 Markdown 文件保存

**Why:** 用户希望系统学习软件工程而非零散知识点，需要按书单体系结构化推进。

**How to apply:** 按用户节奏推进，每次聚焦一个概念。SOLID 完成后进入设计模式阶段。
