# 软件工程学习路线

> 体系：Milo Yip《游戏程序员学习之路》"软件开发"板块
> 开始日期：2026-07-19
> 教学方式：苏格拉底式 + 游戏场景绑定 + 作业驱动

---

## 核心教材（按教学优先级）

1. 《敏捷软件开发：原则、模式与实践》— Robert C. Martin
2. 《重构：改善既有代码的设计》— Martin Fowler
3. 《代码整洁之道》— Robert C. Martin
4. 《修改代码的艺术》— Michael Feathers
5. 《设计模式》GoF + 《Head First 设计模式》

---

## 四阶段总览

```
阶段一：SOLID 原则 ──── 「这个设计对不对？」
阶段二：设计模式 ──── 「这个场景用什么模式？」
阶段三：重构 ──────── 「这坨烂代码怎么安全改？」
阶段四：整洁+遗留 ──── 「怎么防止写烂？烂了怎么救？」
```
